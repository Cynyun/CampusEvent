# 首次运行数据初始化说明

## 实现位置

- 类：`campusevent-server/src/main/java/com/Cynyun/campusevent/config/DemoDataSeeder.java`
- 触发：Spring Boot 启动完成后由 `ApplicationRunner` 自动执行。
- 方言：使用 `JdbcTemplate` 写标准 SQL，SQLite / MySQL 共用同一套初始化逻辑，不依赖某一家的 `INSERT IGNORE` 或自增语法。
- 幂等：`app_meta` 表写入 `demo_seeded=v1` 标记；已有标记时直接跳过。
- 保护：如果 `activity` 表已有数据（例如原 MySQL 库），只写标记，不覆盖、不重复插入。

## 初始化内容

| 数据 | 数量 | 说明 |
|---|---|---|
| 活动 | 8 | 志愿服务、学术讲座、文体活动、创新创业等；DIRECT / APPROVAL 混合 |
| 学生账号 | 36 + 1 | student01—student36，另保留 student 演示账号 |
| 管理员账号 | 1 | admin |
| 报名记录 | 116 | 约 80 条 APPROVED、36 条 PENDING |
| 站内通知 | 116 | 与报名记录一一对应，未读 |

所有账号密码均为 `123456`。活动开始时间按首次启动当天向后推 5—23 天，保证演示时都处于“报名中”。

## 关闭与重置

关闭批量数据（仍创建 student / admin）：

```powershell
$env:CAMPUSEVENT_SEED_DEMO = "false"
```

SQLite 重置（会删除本地演示数据）：

```powershell
# 先停止后端
Remove-Item -LiteralPath .\campusevent.db -Force
# 重新启动后会自动建表并重新初始化
```

MySQL 重置只允许在确认是项目库 `campusevent` 时执行：

```sql
DROP DATABASE campusevent;
CREATE DATABASE campusevent
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

> 不要对非 `campusevent` 的其他数据库执行删除操作。

## 验证

~~~powershell
java -jar target\campusevent-server.jar
# 日志应出现：
# 首次运行初始化完成：8 个活动，36 个学生账号，116 条报名记录
~~~

重启后日志应变为：

~~~text
演示数据已初始化过，跳过
~~~

SQLite 可直接核对：

~~~powershell
python -c "import sqlite3; c=sqlite3.connect('campusevent.db'); print(c.execute('select count(*) from activity').fetchone()[0], c.execute('select count(*) from registration').fetchone()[0])"
~~~
